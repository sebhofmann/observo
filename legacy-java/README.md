# legacy-java

This directory contains the previous JavaFX implementation of Observo. It is kept for
reference and for users who still need to compare behaviour while migrating.

The active implementation is the Rust application in the repository root. See the main
[`README.md`](../README.md) for build and usage instructions.

Configuration from this version (`~/.config/observo/observo.properties`) is migrated
automatically by the Rust application on first start.
